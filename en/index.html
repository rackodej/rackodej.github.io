Discourse SNS webhook RCE

An unqualified call to open(value) is Kernel.open(value): a path opens a file, while a string beginning with | starts a process with an I/O channel.

The URI.open(value) call is also deceptive: anything that is not recognised as a URI is passed back to Kernel.open.

Example:

require "open-uri"
URI.open("|id") { |io| io.read }

postMessage targetOrigin bypass via IP normalization

The regex https?://[^.]+[.]target[.]com accepts http://2130706433/.target.com: [^.]+ means one or more characters other than ., so it consumes 2130706433/ — including /.

As a result, postMessage sends data to http://127.0.0.1, rather than to the target.com subdomain.
