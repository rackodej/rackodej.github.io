> Antares-1B

Antares-1B is a small Cisco security model based on Granite 4.0. It was fine-tuned with SFT[1] + GRPO[2] to find vulnerable code regions through its own agent harness.

This model can augment SAST results in CI/CD. Send the “highlighted” files to larger models for taint analysis.

A full scan of DVJA searching for CWE-78 finished in 39 seconds and found a vulnerability in PingAction.java. It failed badly on OWASP BenchmarkJava.

Requirements

  • Python 3.11+ and uv
  • A Hugging Face account with approved access to fdtn-ai/antares-1b

For Metal, use the ready-made 8-bit MLX quantization: dpoled/antares-1b-mlx-8bit.

Installation

Download the official CLI, create an environment, and fetch the model:

mkdir -p ~/antares-mlx
cd ~/antares-mlx

python3 -m pip install -U "huggingface_hub[cli]"
hf auth login

# Do not forget the access-approval form.
hf download fdtn-ai/antares-1b --include "*.zip" --local-dir ./assets

unzip ./assets/assets/antares-cli.zip -d ./cli

uv venv runtime
uv pip install --python runtime/bin/python mlx-lm fastapi uvicorn
uv pip install --python runtime/bin/python ./cli

# About 2 GB.
HF_HUB_DISABLE_XET=1 hf download dpoled/antares-1b-mlx-8bit --local-dir ./model

A custom completion proxy

The Antares CLI calls an OpenAI-compatible /v1/completions endpoint and sends XML tool calls to its agent. The built-in mlx_lm.server supports the OpenAI API but may handle tool calls itself. That does not work for Antares: the XML must be returned to the client unchanged.

So, run a small local proxy: it uses MLX for inference but returns the text stream as-is.

Save mlx_raw_server.py next to the model directory:

from pathlib import Path
from typing import Literal

from fastapi import FastAPI
from fastapi.responses import StreamingResponse
from pydantic import BaseModel, Field
from mlx_lm import load, stream_generate
from mlx_lm.sample_utils import make_sampler
import json

MODEL_ID = "antares-1b-mlx-8bit"
MODEL_PATH = str(Path(__file__).resolve().parent / "model")

app = FastAPI()
model, tokenizer = load(MODEL_PATH)

class CompletionRequest(BaseModel):
    model: str
    prompt: str
    max_tokens: int = Field(default=1024, ge=1, le=4096)
    temperature: float = Field(default=0.0, ge=0.0)
    top_p: float = Field(default=1.0, gt=0.0, le=1.0)
    stream: bool = True

@app.get("/v1/models")
def models():
    return {"object": "list", "data": [{"id": MODEL_ID, "object": "model"}]}

@app.post("/v1/completions")
def completions(request: CompletionRequest):
    def events():
        sampler = make_sampler(
            temp=request.temperature,
            top_p=request.top_p,
        )
        for response in stream_generate(
            model, tokenizer,
            prompt=request.prompt,
            max_tokens=request.max_tokens,
            sampler=sampler,
        ):
            payload = {
                "id": "antares-local",
                "object": "text_completion",
                "choices": [{
                    "index": 0,
                    "text": response.text,
                    "finish_reason": None,
                }],
            }
            yield f"data: {json.dumps(payload)}\\n\\n"
        yield "data: [DONE]\\n\\n"

    return StreamingResponse(events(), media_type="text/event-stream")

The model is small and starts very quickly:

cd ~/antares-mlx
runtime/bin/python -m uvicorn mlx_raw_server:app --host 127.0.0.1 --port 8081

Check it:

curl http://127.0.0.1:8081/v1/models

First scan

Set the local proxy address and start a scan. It creates a read-only snapshot, limited to 100,000 files and 2 GB, so do not automatically scan open-source mirrors.

cd ~/antares-mlx

export ANTARES_MODEL=antares-1b
export ANTARES_ENDPOINT=http://127.0.0.1:8081/v1/completions
export ANTARES_DATA_DIR="$PWD/data"

runtime/bin/antares query ../dvja --cwe CWE-78 --tool-budget 50 --output "$PWD/report"

--tool-budget 50 is the agent action budget: file searches, code-fragment reads, and other steps. The maximum is 50.

It produces Markdown, JSON, and SARIF. The result is simply the file name in which it found something :) with no details, because it does file-level vulnerability localization: in PingAction.java, something looks suspiciously like CWE-78.

Antares CLI

It looks like an interesting tool for debugging the model’s results.

antares query scans repositories for specified CWEs.

antares sweep selects CWEs automatically or uses those supplied explicitly.

antares plan shows which CWEs would be selected without calling the model.

antares models shows information about the connected model.

antares runs lists runs and traces.

antares completion provides shell completion.

antares tool provides JSON-RPC over stdin.
