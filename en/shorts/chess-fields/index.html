> How to Memorize Chess Squares?

Question
Answer

Square colour

v1

Rather than memorising all 64 squares, assign numbers to the files: a=1, b=2, c=3, d=4, e=5, f=6, g=7, h=8.

To determine a square’s colour, add the file number and the rank number.

If the sum is EVEN — the square is black.

If the sum is ODD — the square is white.

Examples

  • a1: 1 + 1 = 2 (even) → Black
  • e4: 5 + 4 = 9 (odd) → White
  • h8: 8 + 8 = 16 (even) → Black

v2

The same parity means a black square.

Treat files a, c, e, and g as odd, and b, d, f, and h as even. If the file and rank have the same parity, the square is black; if they differ, it is white.

  • a1: 1 / 1 (odd/odd) → Black
  • e4: 5 / 4 (odd/even) → White
  • h8: 8 / 8 (even/even) → Black
