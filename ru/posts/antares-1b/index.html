> Antares-1B

Antares-1B — маленькая security-модель Cisco на базе Granite 4.0. Дообучена через SFT[1] + GRPO[2] для поиска уязвимых участков кода через свой агентский харнес

Эту модель можно использовать для дополнения результатов SAST в CI/CD. “Подсвеченные” файлы отправлять в тяжелые модели для taint-анализа.

Полный проход по DVJA: поиск CWE-78 завершился за 39 секунд и нашёл уязвимость в PingAction.java. На OWASP BenchmarkJava фолзил нещадно.

Что потребуется

  • Python 3.11+ и uv
  • аккаунт Hugging Face с одобренным доступом к fdtn-ai/antares-1b

Для Metal используется готовая 8-битная MLX-квантовка dpoled/antares-1b-mlx-8bit

Установка

Качаем официальный CLI, окружение и модель:

mkdir -p ~/antares-mlx
cd ~/antares-mlx

python3 -m pip install -U "huggingface_hub[cli]"
hf auth login

# Не забываем про формочку апрува
hf download fdtn-ai/antares-1b --include "*.zip" --local-dir ./assets

unzip ./assets/assets/antares-cli.zip -d ./cli

uv venv runtime
uv pip install --python runtime/bin/python mlx-lm fastapi uvicorn
uv pip install --python runtime/bin/python ./cli

# Около 2 гигов
HF_HUB_DISABLE_XET=1 hf download dpoled/antares-1b-mlx-8bit --local-dir ./model

Свой completion-proxy

CLI Antares обращается к OpenAI-совместимому endpoint /v1/completions и передаёт агенту XML-вызовы инструментов. Встроенный сервер mlx_lm.server умеет OpenAI API, но может обработать tool calls самостоятельно. Для Antares это не подходит, XML должен вернуться клиенту без изменений.

Поэтому запускаем маленький локальный proxy: использует MLX для инференса, но отдаёт поток текста в исходном виде

Сохраняем рядом с каталогом model файл mlx_raw_server.py

from pathlib import Path
from typing import Literal

from fastapi import FastAPI
from fastapi.responses import StreamingResponse
from pydantic import BaseModel, Field
from mlx_lm import load, stream_generate
from mlx_lm.sample_utils import make_sampler
import json

MODEL_ID = "antares-1b-mlx-8bit"
MODEL_PATH = str(Path(__file__).resolve().parent / "model")

app = FastAPI()
model, tokenizer = load(MODEL_PATH)

class CompletionRequest(BaseModel):
    model: str
    prompt: str
    max_tokens: int = Field(default=1024, ge=1, le=4096)
    temperature: float = Field(default=0.0, ge=0.0)
    top_p: float = Field(default=1.0, gt=0.0, le=1.0)
    stream: bool = True

@app.get("/v1/models")
def models():
    return {"object": "list", "data": [{"id": MODEL_ID, "object": "model"}]}

@app.post("/v1/completions")
def completions(request: CompletionRequest):
    def events():
        sampler = make_sampler(
            temp=request.temperature,
            top_p=request.top_p,
        )
        for response in stream_generate(
            model, tokenizer,
            prompt=request.prompt,
            max_tokens=request.max_tokens,
            sampler=sampler,
        ):
            payload = {
                "id": "antares-local",
                "object": "text_completion",
                "choices": [{
                    "index": 0,
                    "text": response.text,
                    "finish_reason": None,
                }],
            }
            yield f"data: {json.dumps(payload)}\\n\\n"
        yield "data: [DONE]\\n\\n"

    return StreamingResponse(events(), media_type="text/event-stream")

Модель маленькая и стартует очень быстро:

cd ~/antares-mlx
runtime/bin/python -m uvicorn mlx_raw_server:app --host 127.0.0.1 --port 8081

Проверяем:

curl http://127.0.0.1:8081/v1/models

Первый скан

Указваем адрес локального proxy и запускаем проверку. Из ограничений – создаёт read-only snapshot и ограничивает его 100 000 файлов и 2 ГБ, так что никаких автосканов для зеркал опенсорса

cd ~/antares-mlx

export ANTARES_MODEL=antares-1b
export ANTARES_ENDPOINT=http://127.0.0.1:8081/v1/completions
export ANTARES_DATA_DIR="$PWD/data"

runtime/bin/antares query ../dvja --cwe CWE-78 --tool-budget 50 --output "$PWD/report"

--tool-budget 50 — бюджет действий агента: поиск файлов, чтение фрагментов кода и другие шаги. Максимум – 50

В результате создаёт Markdown, JSON и SARIF. Просто с именем файла где нашёл :) без подробностей, потому что работает как file-level vulnerability localization, то есть в файле PingAction.java выглядит что-то подозрительно похоже на CWE-78

Antares CLI

Выглядит как любопытный инструмент для отладки результатов модели

antares query проверяет репы по указанным CWE

antares sweep выбирает CWE автоматически или использует переданные явно

antares plan показывает, какие CWE будут выбраны, не вызывая модель

antares models инфа по подключенной модели

antares runs запуски и трейсы

antares completion автодополнение для shell

antares tool JSON-RPC для работы через stdin
