postMessage targetOrigin bypass via IP normalization

Регулярка https?://[^.]+[.]target[.]com пропускает http://2130706433/.target.com: [^.]+ означает один или больше любых символов, кроме ., поэтому съедает 2130706433/ — в том числе /.

В итоге postMessage отправляет данные на http://127.0.0.1, а не на поддомен target.com.
